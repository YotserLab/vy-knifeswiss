# Network Swiss Knife

Um aplicativo Android multifuncional projetado para ser um canivete suíço para tarefas comuns de rede e utilitários.

## Funcionalidades principais:

- **Backup & Cloud**: Integração para gerenciar backups locais (JSON export/import) e sincronização configurável com Google Drive para dados de Kanban, Alarmes e Calendário.
- **Menu Lateral (Drawer)**: Menu de navegação estilo "hambúrguer" agora disponível em TODAS as ferramentas para acesso rápido.
- **Ferramentas de Rede**: Monitor de Wi-Fi, Port Scanner, Testes de rede (Ping), Subnet Scanner, Speed Test.
- **Utilitários**: Nível de bolha, Bússola, Calculadora HP 48G (RPN), Device Info (System & Hardware - clone com.ytheekshana.deviceinfo), Gerenciador de Arquivos, Terminal & SSH.
- **Produtividade**: Audit History & PDF (para exportação de relatórios de uso), Notas & Kanban, Calendário & Alarmes inteligentes.
